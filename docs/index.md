# FCS Donations

O FCS Donations registra intenções de doação, consulta campanhas e publica eventos de domínio para processamento assíncrono.

## Operação

- Namespace Kubernetes: `fcs-donations`
- Health check: `/health`
- Métricas: `/metrics`
- API: `/api/v1`

Consulte o [README](../README.md) para requisitos, execução local e contratos da API.
